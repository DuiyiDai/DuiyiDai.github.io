# Duiyi (Claire) Dai — personal website

[Visit the website](https://duiyidai.github.io/)

Professional and research profile of Duiyi (Claire) Dai, an empirical economist and data scientist working in Equity Research at UBS, with a PhD in Economics from the University of Birmingham.

The website brings together publications, working papers, policy engagement, research software, education and teaching.

## Repository structure

- `index.html`: current homepage, including research and professional experience.
- `assets/css/portfolio.css`: homepage styling and responsive layout.
- `assets/images/`: portrait, institution marks and project assets.
- `_config.yml`: Jekyll configuration.
- `_pages/`, `_layouts/`, `_includes/` and `_data/`: supporting pages and Jekyll resources.

## Publishing

GitHub Pages publishes this repository from the root of the `main` branch. The homepage uses its own HTML layout; keep its front matter when editing it.
